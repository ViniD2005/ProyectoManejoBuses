# Estructura del sistema

- `index.html`: portada.
- `pages/viajes.html`: búsqueda de viajes.
- `pages/asientos.html`: selección y validación de cantidad de asientos (demo).
- `pages/pasajeros.html`: formulario dinámico por pasajero (demo).
- `pages/resumen.html`: resumen de reserva (demo).
- `pages/pagos.html`: solicitud de pago (demo).
- `pages/reservas.html`: futuras reservas y boletos.
- `pages/wallet.html`: futuro monedero.
- `pages/cooperativa.html`: futura administración de flota.
- `pages/conductor.html`: futura validación de embarque.
- `pages/login.html`: futura autenticación.
- `assets/js/data.js`: datos ficticios.
- `assets/js/app.js`: interacciones de demostración.
- `backend/`: especificaciones iniciales, NO servidor funcional.
- `database/schema.sql`: esquema SQL de referencia.
- `.github/`: plantilla de PR y CI.

## Pendiente para producción
Autenticación, permisos, API, base de datos real, disponibilidad transaccional, descuentos legales, comprobación de pago, emisión de boletos, protección de datos y pruebas integrales.
